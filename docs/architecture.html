Reliability

A slow render or a failed call cannot skip the day, and cannot post twice.

  • Retries with backoff. HTTP steps retry timeouts and 5xx. The wait doubles.
  • Timeouts. Each poll loop (still, clip, render, Instagram container) counts its polls and stops at a hard cap.
  • Cost cap per run. Paid image, video, voice, and render calls are checked against COST_CAP_USD before each pass, regenerations included. Free calls cost zero.
  • Alerting. A separate Error Trigger workflow names the failed step.
  • Idempotency. The reel id is written to the dedupe log after a successful publish. Later runs skip logged ids. A failed run leaves the reel for another day, up to a fixed number of starts.
